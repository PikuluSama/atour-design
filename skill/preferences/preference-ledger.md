# 中央偏好账本(跨项目通用规则)

> 由「自进化机制」维护(见 `references/foundation/preference-ledger.md`):Ed 的反馈抽象成规则后追加于此。
> **每次设计任务开工前必读**(偏好探测第 3 步);与 profile 静态描述冲突时,账本赢。
> 🔴 本账本只收**跨项目通用**规则;项目专属规则写各项目 `.eds-design/profile.md` 的 ledger 段。
> 🔴 品牌专属规则不在此——只进对应项目的 `.eds-design/profile.md`。

## 规则格式

```
### P-{编号} · {规则一句话}
- 级别:硬禁令 / 强偏好 / 情境规则
- 何时适用:{范围}
- 原话摘录:「{Ed 当时的表述}」
- 收录:{日期}｜来源:{场景}｜状态:生效 / 已废止({日期,原因})
```

### P-1 · 设计方向必须从用户的「时刻/场景」推导,风格先行(视觉概念领题)会被否
- 级别:硬禁令
- 何时适用:三方向初稿的立意阶段——先从「用户打开的头 30 秒想知什么/做什么」推出每稿的信息骨架与主角,视觉风格只作为骨架的着装;禁止用视觉母题(如某种波形/材质)当组织原则。
- 原话摘录:「这三个方向的内容我都很不满意」(此前风格先行的三方向全被否;随后从场景推出的概念「打开即答案」获认可)
- 收录:2026-08-09｜来源:Pulse v2 重设计｜状态:生效

### P-2 · Ed 反问「你怎么想」时要给带立场的强观点,不要回抛问卷
- 级别:强偏好
- 何时适用:Ed 把问题抛回(如「如果你是乔布斯你怎么想」)——先给一个连贯、敢否掉东西的观点与推导,再交给他否决或选择;选择题放在观点之后,不作为开场。
- 原话摘录:「我也不知道,如果你是乔布斯,你会怎么思考这个事情」
- 收录:2026-08-09｜来源:Pulse v2 重设计｜状态:生效

### P-3 · 图标库统一 Heroicons 首选(Tailwind 官方),Font Awesome 备选
- 级别:强偏好
- 何时适用:所有设计产出(原型/页面/卡片/deck/动画)凡需图标处;禁 emoji 当图标。装饰性 icon 仍守基座克制原则——「能不用就不用,用则服务功能识别」,不因有图标库而堆 icon。
- 原话摘录:「涉及到图标类的使用 Tailwind 的」(2026-08-10 指定,记入 10-Work profile 与 brand-spec §5;2026-08-11 Ed 确认「提升」为全场景通用)
- 收录:2026-08-11｜来源:明确指定+提升确认｜状态:生效
