# 基座 #7 · 排版(含中文排版)

> 这不是字体清单,是**配对与排版的推理规则**。目标:同一个风格标签,落到不同内容上,推导出不同的排印结果,而不是每次抄同一套字号。
> 前置纪律:有 design context 先 lift Ed 自己的字体(项目 profile / 品牌 spec),本文只在「没有字体规范」时启用。

## 排印决策顺序(不许跳到「直接选个好看的字体」)

1. **内容类型** → 长文阅读 / 数据密集 / 营销大字 / UI 界面,决定音阶比例和正文字号
2. **语言构成** → 纯中文 / 中西混排 / 纯西文,决定 fallback 链写法和行高基准
3. **风格温度**(安静/中性/大胆)→ 决定字体配对的对比度来源
4. **最后才是字体名**

为什么:先选字体名会让「内容是什么」对排印零影响——这正是千人一面的病根。

## 字号音阶(modular scale)

字号从正文字号乘固定比例逐级推出,比例决定页面戏剧性:

| 比例 | 性格 | 适用 |
|---|---|---|
| 1.2 | 平缓、层级多而不吵 | dashboard、文档站、信息密集 UI |
| 1.25 | 通用、安全 | 大多数网页、产品落地页 |
| 1.333 | 标题明显跳出 | editorial 长文、营销页、报告 |
| 1.5 | 戏剧性、层级极少 | 大字报、slides、hero 一屏一句 |

正文定 16-18px(**中文正文建议 17-18px**——汉字笔画密,同字号比西文显挤),按比例上推标题、下推 caption。层级超过 5 档就是失控,砍掉。display 档(hero 巨字)脱离音阶,用 `clamp()` 按视口推:`font-size: clamp(3rem, 1rem + 9vw, 9rem)`。

## 行长与行高

| 语言 | 舒适区 | CSS |
|---|---|---|
| 西文正文 | 45-75 字符,最佳 66 | `max-width: 65ch` |
| 中文正文 | 一行 22-38 字,最佳 28-32 | `max-width: 36em` |

行高是行长的函数——行越长,回行距离越远,需要更大行间距当「轨道」。中文正文行高 1.6-1.8 起步,西文 1.5-1.6。

## 中文排版要点(凡界面含中文,本节优先级高于通用西文规则)

完整版含字重陷阱/配色/数字规范 → `library/chinese-typography.md`(qiaomu 原文,蒸馏自 W3C clreq + Ant Design + Apple HIG 中文版)。硬规则摘要:

- **字体加载纪律**:中文一律系统字体栈(`-apple-system, "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "Noto Sans SC", sans-serif`)——中文 webfont 单文件 5-20MB;装饰性中文字体**只允许**在创意标题场景 + Google Fonts `text=` 子集化 + `font-display: swap`;思源黑/宋全量引入也算违规
- **字重陷阱**:中文字体多数只有 400/700,中间字重是伪合成发虚;苹方没有 Bold(700 落到 600)。正文 400,标题/强调写 **500 或 600**,不写 bold;层级靠字号 + 颜色,字重只辅助
- **参数**:行高 **1.5-1.75**(比英文更大);正文 ≥14px(高密度用 16px);每行桌面 30-40 字/移动 18-25 字;禁负字距
- **盘古之白**:中英文之间、中文与数字之间加空格(`在 Lumina 上使用 SDK`、`共 500 条记录`);数字与单位间加空格,**例外** `90°`、`15%` 不加;全角标点前后不加
- **标点**:全角标点不夹半角;破折号 `——` 占两字宽不拆行;禁叠用标点(「!!!」);**中文禁斜体**(无斜体字形,强制倾斜 = 笔画变形——此条是硬禁令,全场景生效);下划线只留给链接
- **中文界面配色**:中性文字用透明度写法(亮色主文 `rgba(0,0,0,.88)`/次 `.65`/禁用 `.25`);**暗色页正文不用纯白**:`.85`;中文笔画在暗底损失更大,暗色正文对比度按 **7:1(AAA)** 设防,不是西文常用的 4.5:1
- **数字**:一律半角;界面数字 `font-variant-numeric: tabular-nums`

## 可读性硬底线(任何风格不豁免,含「奢侈留白」安静派)

- 正文 ≥14px,标签/注释 ≥12px
- 正文对比度 ≥4.5:1(WCAG AA)
- 留白必须是**构图**(首屏有视觉锚点、视线有落点),不是内容缺席——「大片死白 + 微缩字号」看起来像页面渲染坏了
