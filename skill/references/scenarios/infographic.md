# 场景 · infographic(信息图 / 观点图)

> 触发:「信息图」「观点图」「一张图讲清楚」「印刷级排版」「数据说明图」
> 产物:精确排版、数据驱动、印刷级质量的单页/长图,可导 PDF/PNG/SVG
> embody:平面设计师(编辑设计方向)

## 定位

信息图是**把论证变成版面**:一个核心观点 + 支撑结构 + 精确排印。不是把图表堆在一起——那是 dashboard。

## 工作要点

1. **先定论证结构**:核心论点一句话 → 支撑点 3-5 个 → 每个支撑点的证据形态(数字/对比/流程/引语)。结构不成立不要碰视觉
2. **form 推导五问必答**(基座 core-philosophy):信息图的第 5 问「视觉母题」尤其关键——观点图没有母题 = 模板套皮
3. **排版走印刷级标准**:字号音阶 1.333(纯四度)起步、中文行长 22-38 字、网格对齐到 4px 基线、`text-wrap: pretty`
4. **数字与事实**:信息图里的每个数字都可追溯——Ed 没给数据就留诚实 placeholder(「数据待补」),**绝不编造看起来像数据的假数据**(data slop 是信息图的死罪)
5. **图表绘制**:需要统计图表(bar/line/scatter/heatmap)→ **调用 `dataviz` skill** 的规范,不自己发明图表语法
6. **导出**:PDF(印刷)/ PNG(社交分发,注意尺寸走 social-card 规格)/ SVG(矢量)

## 三方向门适配

信息图三方向初稿 = 每方向 1 个完整 HTML + 截图(首屏即可,不用全图)。

## 验收

- [ ] 核心论点一句话可复述
- [ ] 每个数字有出处(或标注待补)
- [ ] 网格/基线对齐,无 1-2px 漂移
- [ ] 基座工程清单的可访问性项(对比度/alt)通过
