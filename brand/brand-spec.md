## 0. 双层设计语言（最重要的一条）

亚朵星球的视觉分**两层**，做设计前先判断自己在哪层：

| 层 | 适用范围 | 语言 |
|---|---|---|
| **品牌层（VI）** | 品牌物料、营销、包装、海报、品牌向 deck | 深睡蓝 `#002a40` + 蓝系辅助色；方正兰亭黑 + Basis Grotesque |
| **数字产品层（H5 实测）** | 商城 H5、交易/导购 UI、以及 PM 后台原型的组件语感 | 黑白灰中性 + 陶土橙 accent `#e56a54`；PingFang SC + DIN Condensed 数字 |

- 品牌/营销向产出 → 用 VI 层。
- 商城/交易/工具向原型 → 组件语感跟 H5 实测层（克制、白底、黑按钮、小圆角），品牌蓝只出现在**品牌标识/品牌区块**，不全页面铺蓝。
- 拿不准 → 默认「H5 组件语感 + VI 品牌点缀」，并在交付说明里注明。
- **品牌主体判定先于双层判定**：产出服务于**亚朵集团**（集团品牌/雇主品牌/集团级营销）时，色彩走 §2.4 集团配色；本节双层只适用于亚朵星球产出。两套配色不混用于同一产出。
- **单方向直出**：10-Work 内原型不做多方向草稿供选择，直接按本规范产出唯一方向（Ed 指定 2026-08-10；eds-design 三方向门在本项目豁免）。

## 3. 字体

| 场景 | 中文 | 西文/数字 | 规则 |
|---|---|---|---|
| VI 品牌层 | **方正兰亭黑**（优先：中黑/黑/纤黑简体；层级多时可用大黑/粗黑/中粗黑/超细黑） | **Basis Grotesque** | 西文 x 高与中文视觉一致、基线视觉一致；**同一层级中西文字号不得相同** |
| 数字产品层 | PingFang SC（系统栈） | 数字/价格 **DIN Condensed**（font-weight 500） | H5 实测；价格数字用 DIN，其余系统栈 |

Web 原型字体栈建议：`-apple-system, "PingFang SC", "Helvetica Neue", sans-serif`；品牌 display 场景方正兰亭黑缺 Web 授权时退 PingFang SC 中黑体感，**不得**用 Inter 作 display。

## 4. 组件语感（H5 实测 · 750 设计基准，vw 换算 1vw≈3.75px@375）

- **按钮**：黑底白字为主 CTA；小圆角 `1.06667vw`≈4px（方角感，非胶囊）；高 8.53vw≈32px（small）/12.27vw≈46px（large）；仅个别场景胶囊（8vw）。
- **卡片**：白底、圆角 4~8px、极轻阴影 `0 1px 5px hsla(0,5%,91%,.5)`；商品图区 44vw 高。
- **搜索/胶囊**：圆角 6.67vw≈25px 全圆角，半透明白底。
- **价格**：`￥`+数字 baseline 对齐；数字 DIN Condensed 加粗；活动价 `#e56a54`；划线价 `#a9aaaa`。
- **文字色阶**：#333（商品名 700）→ #67696a → #a9aaaa。
- 整体：**少 border、少装饰 icon、留白克制**；暖白 `#f2f1ef` 代替冷灰做禁用/分隔底。

## 5. 图标库（Ed 指定 2026-08-10）

- 首选 **Heroicons**（Tailwind 官方出品）；备选 Font Awesome。
- 原则沿用 eds-design 基座：装饰性 icon 能不用就不用；图标服务于功能识别。
- 禁拿 emoji（📦⚠️🔥 等）当图标——旧原型不专业感的主要来源，平台渲染不一致。

## 8. 运营后台（OPS）组件语言（2026-08-10 增订 · 原型仓库审阅版）

> 来源：审阅 prototype 部署仓库（github.com/PikuluSama/prototype）16 份归档原型，重点 v1.7 代（内购赠品订单自动创建 / 售后流程重构规划）。结论固化如下：新做/改版后台原型**直出本节**，不再临场发挥配色。

### 8.1 现状问题（为什么改）

- 语义色照搬 Material 默认（`#4CAF50`/`#FF9800`/`#E53935` + 100 系浅底），与品牌克制蓝灰冲突；
- 中性阶偏冷（`#1a2332`/`#6b7a8d`/`#eef1f5`），与 H5 实测暖白体系（§2.3）两套灰并存；
- 字体 Noto Sans/Serif SC，两套品牌字体体系都没踩中；
- emoji 当图标（🔥📦️），跨平台不一致、廉价感；
- 圆角历代混用 4~20px；更早版本还有墨绿+金、紫渐变、AntD 绿等脱品牌语言残留。
- **保留的好底子**：v1.7 `:root` token 化写法（注释引 VI）、深色侧栏+浅色内容布局、面包屑、编号标注点（走查讲解技法）、表格/筛选/批量操作结构、数据复盘仪表盘的品牌蓝图表用法。

### 8.2 OPS token（直出单一标准）

| Token | 值 | 用途 |
|---|---|---|
| 侧栏/品牌区块 | `#002a40` | 侧栏底、页顶品牌区——品牌蓝只作"区块"，不全屏铺 |
| 选中/链接/focus | `#275e80` | 导航选中、链接、focus ring、active tab |
| 主按钮 | `#272a2b` 墨黑 | 主 CTA（延续 H5 黑按钮语感） |
| 文字 1/2/3 阶 | `#333` / `#67696a` / `#a9aaaa` | 标题正文/次级/弱（H5 实测色阶） |
| 边框/分隔 | `#d4d4d5` / `#e6e5e2` | 输入与按钮边/表格分隔线 |
| 页面底/卡片 | `#f9f9f9` / `#fff` | 页面底、卡片白底 |
| 禁用/斑马/hover | `#f2f1ef` 暖白 | 禁用底、行 hover、条纹底——禁冷灰替代 |
| accent 陶土橙 | `#e56a54`；强调 `#a54e3d` | 数据高亮、金额强调、选中态；深陶土做强调 tag |
| success | `#4a7d5f`，浅底 `#edf3ee` | 成功/正常/通过 |
| warning | `#a9702c`，浅底 `#f6efe4` | 警告/超时/拦截中 |
| danger | `#bf4436`，浅底 `#f8eceb` | 错误/高风险/失败 |
| info | `#275e80`，浅底 `rgba(39,94,128,.08)` | 信息/进行中 |
| 数字字体 | DIN Condensed（500） | 金额、件数、统计大数（对齐 H5 价格数字） |
| 正文字体 | 系统栈 PingFang SC | 标题同族加粗即可，**不用衬线**；品牌区块兰亭黑体感 |
| 圆角 | 控件/tag 4px；卡片 8px | 禁 ≥12px 与胶囊（头像除外） |
| 阴影 | `0 1px 3px rgba(0,0,0,.04)`；卡片 `0 1px 5px hsla(0,5%,91%,.5)` | 极轻、中性，禁蓝灰重投影 |
| 图标 | Heroicons outline 16/20px | 禁 emoji |

### 8.3 组件约定

- **状态表达**：优先「同系文字+浅底 4px tag」或「纯文字+色点」；整行色底/左侧色条只留给 danger 高危强调。
- **表格**：行高 48~56px，分隔 `#e6e5e2`，hover 暖白；金额/件数 DIN Condensed 右对齐。
- **筛选栏**：白底卡片，控件高 32px；主操作墨黑+次级白按钮靠右。
- **侧栏**：`#002a40` 底白字；选中项 `#275e80` 块或左 2px 指示条；分组小标用 `#9dc6c6` 或 60% 白。
- **空态**：灰线描图+一句指引；禁 emoji 与彩色卡通贴图。
- **标注点**（走查技法保留）：统一 `#275e80` 圆点白字 18px。
- **图表**：主系列 VI 蓝三阶 `#002a40/#275e80/#9dc6c6`，对比系列暖米 `#beb8b4`；语义色只点异常条。样板=「小程序促销机制数据复盘」仪表盘（现存最贴品牌的后台页）。
